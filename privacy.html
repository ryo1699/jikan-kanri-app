プライバシーポリシー

最終更新日: 2026年10月14日

本ポリシーは、Mac アプリ「時間管理」（以下「本アプリ」）が Google ユーザーデータをどのように扱うかを説明するものです。

1. 取得する情報

Google アカウントと連携した場合、本アプリは次の情報を取得します。

  • Google アカウントのメールアドレス（連携中のアカウントを表示するため）
  • Google カレンダーのカレンダー一覧と予定（タイトル、開始・終了時刻）

カレンダーへのアクセス権限は読み取り専用（calendar.readonly）です。

2. 利用目的

取得した予定は、本アプリのタイムライン上に下書きとして表示するためだけに使用します。

3. 保存と第三者への提供

  • 認証情報（リフレッシュトークン）と予定のデータは、お使いの端末内にのみ保存します。
  • 開発者のサーバーを含め、外部へ送信することはありません。通信は Google の API との間でのみ行います。
  • 第三者への提供・販売は行いません。広告目的には使用しません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. 連携の解除とデータの削除

本アプリの設定画面から連携を解除できます。また、Google アカウントのサードパーティ アクセスからいつでもアクセス権を取り消せます。本アプリを削除すると、端末内に保存されたデータも削除されます。

6. お問い合わせ

GitHub の Issues からご連絡ください。
